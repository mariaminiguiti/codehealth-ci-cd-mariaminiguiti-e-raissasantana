# codehealth-ci-cd-mariaminiguiti-e-raissasantana
Projeto de Integração Contínua (CI/CD) e Gerência de Configuração.

O projeto visa aplicar os princípios de Integração Contínua (CI/CD) e Gerência de Configuração através da criação da primeira versão de um pipeline CI/CD simples para a startup CodeHealth. O propósito é automatizar o fluxo de trabalho de desenvolvimento, garantindo testes e implantação segura das atualizações do sistema de agendamento médico e controlando as versões de código e infraestrutura, alinhado à adoção de práticas DevOps.
